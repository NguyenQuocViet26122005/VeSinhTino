# Tino project guidance

Before changing visual UI, read DESIGN.md and the relevant source components. It documents the shared blue theme across all routes and the distinct interior-page layouts.

Use the installed project skills selectively. Preserve verified contact details, prices, images and existing routes. Follow the reduced-motion and mobile rules in DESIGN.md. Respect all third-party licenses.

Validation: npm run design:lint for design documentation; npm run check, npm run build and npm run verify for source changes. Inspect relevant UI at desktop and mobile sizes after visual changes. Keep the preview on localhost unless the user authorizes deployment.
